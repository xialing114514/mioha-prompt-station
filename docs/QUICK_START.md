# 快速上手

[手册目录](README.md) · [项目主页](../README.md)

## 下载与安装

从 [最新 Release](https://github.com/xialing114514/mioha-prompt-station/releases/latest) 下载 `Mioha-Prompt-Station-版本号-Setup.exe`。`mioha-model-skills-v15.zip` 是独立规则包，不是软件安装器，也不是 WD14 权重。

运行安装器，选择安装目录，按需创建桌面快捷方式。需要 Windows 10/11 x64 与 Microsoft Edge WebView2 Runtime。程序自带必要运行组件，普通用户不用安装 Python、Node.js，也不用打开命令行。

安装包没有发布者数字签名。请核对下载来源及同一 Release 的 SHA256；遇到系统拦截先确认文件来源和系统提示。

## Android 与手机连接

4.0 提供独立 Android arm64 APK，下载 `Mioha-Android-4.0.0-arm64.apk`。覆盖安装保留本地资料；模型接口和凭据保存在自己的设备中。手机可以独立编辑和使用 AI，也可以配对电脑执行绘图。配对、回执、确认与重连见 [手机连接指南](MOBILE_REMOTE.md)。

## 4.0.0 电脑端启动报 DNSName / A-label

这是 4.0.0 对中文 Windows 电脑名处理的缺陷，已在 4.0.1 修复。请覆盖安装新版，不需要改电脑名，也不要删除个人资料、设备身份或证书文件。手机版 4.0.0 继续兼容。

## 第一次进入

软件默认安全模式，当前可见标签数量会少于完整词库。先使用「提示词选词」或「绘图资料中心 → 角色配方」浏览本地内容。

- 手动选词：搜索中文或英文，点击词条加入当前正向／负向列表。
- 调整：展开「调整权重与顺序」，选中词条后增减权重或输入数值，也可拖动排序。
- 保存：将常用组合保存为预设或存档；在设置中导出数据备份。

## 角色配方保存与手动备份

在「绘图资料中心 → 角色配方」创建或编辑角色，点击保存并等待编辑区收起，代表已提交到本机数据库。关闭页面或重启软件后仍可读取。大正文可导入 UTF-8 TXT，本地按实际磁盘空间保存，不设软件容量配额。

新增角色、浏览页面和启动程序不会自动上传角色配方。需要云端备份时，在设置中配置自己的服务器连接，再点击角色配方工具栏的「上传服务器」。只上传已经保存的角色资料与正文，界面显示上传状态；修改后需再次手动点击。

服务器所有空间共用 1 GB 总容量，不是每人各 1 GB。空间不足、网络断开或上传失败都不会删除本地配方；新快照完整上传和校验后再替换服务器备份。程序重启不会自行重试未完成的上传，再次点击可续传。

## 用内置 AI 生成提示词

1. 打开「AI 选词」，选择实际要使用的绘图模型与 Skill。
2. 免费通道默认是 NVIDIA: Nemotron 3 Ultra (free)；也可关闭免费模式，填写自己的接口、模型和凭据。
3. 描述画面，例如：「傍晚雨中的安静书店，暖灯、木地板、窗边绿植，没有人物，也不要画面文字。」
4. 查看右侧结果，继续补充要求，或复制、追加／替换到编辑器。
5. 要执行绘图时，再点「发送到生图」检查引擎和参数。

已有自定义连接时，配置区默认折叠。点击摘要可展开，编辑后保存。保存的地址及模型名会显示在摘要中。

要批量比较提示词、管理分镜或用蒙版编辑图片，可从[创作工作台指南](CREATIVE_WORKSPACE.md)开始。

内置 AI 调用在线或自行配置的模型，不是离线附带的大语言模型。免费服务不可用时可稍后重试；程序不会自动改用你的自定义 Key。

## 首次读取本地资源

进入资源／LoRA 页面会直接显示路径向导。默认可选择自己的 LoRA 文件夹；若要读取整个引擎目录，可切换为根目录或使用自动查找。选择文件夹、按 Enter 或失焦后会保存并读取，等待处理中状态结束即可。错误路径会直接给出说明，不需要再寻找独立的保存入口。

## 接入绘图引擎

NeoForge、ComfyUI 需要你先启动对应服务，并在软件中填写其本机 API 地址。常见默认地址分别为 `http://127.0.0.1:7860`、`http://127.0.0.1:8188`，实际以引擎的启动信息为准。

目录读取与 API 连接是两件事：设置模型目录可扫描资源，执行绘图还需要运行中的引擎。NovelAI 需要自己的服务凭据；MOSS 等模型需要匹配的组件和工作流。

详见 [模型与生图指南](MODELS_AND_GENERATION.md)。没有启动绘图引擎，也能使用手动选词、角色管理、资料检索以及已安装模型的本地 WD14。

## 内容模式

首次在左侧点「解除 NSFW 限制」会显示警告；可以取消。确认后，后续在设置的「内容显示」中切换。AI 的内容按钮只有全局解锁后才可用，不会改变第三方服务自己的规则。

## 更新与数据

设置中查看版本、检查更新和打开 GitHub。启动时每天最多自动检查一次，也可以关闭自动检查。更新包需由用户安装。

个人数据位于 `%USERPROFILE%/.mioha-prompt-forge`。升级前建议导出备份，卸载不会主动删除该用户数据目录。

### 从服务器下载角色配方

在同一服务器连接下，点击角色配方工具栏的「从服务器下载」。软件下载已完成的备份，校验全部正文后合并到本地；同名角色和已有修改优先使用本地版本，下载不会自动上传。损坏、不完整或超过服务器 1 GB 总容量的备份不会替换本地资料。导入后关闭页面或重启仍可读取。
