# 常见问题

[手册目录](README.md)

### 这是在线网站还是本地软件？

这是 Windows 本地应用，使用本地界面、数据库和运行服务。在线 AI、资料获取、云同步和更新检查按相应功能联网。

### 用之前要安装 Python 或启动命令行吗？

发行安装包提供运行组件，普通使用不需要。NeoForge／ComfyUI 是外部绘图引擎，需要用户自行准备；独立 WD14 不需要启动它们。

### 内置 AI 是本地模型吗？

内置的是 AI 工作区和工具流程，不附带大语言模型权重。免费模式使用第三方在线通道；也可配置自己运行的本地兼容接口。

### 默认免费模型是哪一个？为什么有人显示 Super VL？

默认是 NVIDIA: Nemotron 3 Ultra (free)。程序会保留用户已保存的选择，可点「恢复默认模型」切回 Ultra。清单中存在其他模型不代表程序会自动切换。

### 免费服务不可用会自动用我的自定义 Key 吗？

不会。检查网络、清单和上游状态后重试，或自行切换到想使用的自定义接口。

### 关闭「联网查证」是否完全离线？

关闭的是资料查证流程。若选的 LLM 仍是在线服务，推理请求仍需联网。

### 内置 AI 能读取我新建的角色吗？

能读取同一份本地角色配方，包括新建和编辑后的外观。可以指明「查本地角色配方里的某某」，不要把其他资料来源的空搜索结果等同于配方为空。

### 模型卡出现了，为什么不能直接生图？

模型定义、资料元信息、实际权重与运行引擎分别管理。先确认权重已绑定、引擎在线、组件和工作流匹配。

### LoRA 有触发词却效果不同？

核对底模版本、实际注册名、权重、触发词是否进入最终正向，以及工作流与采样参数。先逐个验证再组合；作者预览不等于任意设置下效果完全相同。

### 预览不显示，是下载失败吗？

安全模式会隐藏 NSFW 和未确认安全的预览。也可能是来源限制、图片失效或网络问题，需查看当前内容模式和错误信息。

### 为什么「解除 AI 限制」不能点击？

先在侧栏首次入口或设置中阅读警告并确认解除全局限制。这个按钮只控制软件自身的内容偏好，不改变上游服务规则。

### WD14 扫描不到我放进去的模型？

最常见是只放了模型、缺少同目录的 `selected_tags.csv`，放错安装目录，或下载到 LFS 指针／网页。按 [WD14 安装教程](WD14.md)逐项检查。

### WD14 为什么没有还原出原始提示词或真实 LoRA？

WD14 是看图预测标签，不能替代文件中的原始生成元数据。软件有元数据时优先展示元数据。

### Agent 连接成功，却没有执行转换？

先读 capabilities／state 的队列状态，确认桌面工作进程在线且可领取任务；查看是否等待补充、确认或前一个任务完成。仅 HTTP 在线不代表可立即执行。

### 卸载、更新或换路径会把角色删掉吗？

个人数据放在用户目录，卸载不会主动清除。迁移前仍建议导出备份，并分别保存自己导入的模型和资源。

### 怎么反馈问题？

使用 [问题表单](https://github.com/xialing114514/mioha-prompt-station/issues/new/choose)，附版本、模块／引擎、复现步骤和脱敏截图。请先查阅本页及已有问题。


### 已授权的 Agent 为什么还在等确认？

新版支持 `confirm_job` 自主确认自己提交的请求。检查 Token 是否包含所需权限、是否选择了始终由用户确认模式，以及外部客户端是否重连到新版 MCP 工具。配置 LoRA 需要 generate 权限，查询资源需要 resources 权限。

### 我的 LoRA 没有完整引擎目录，能单独读取吗？

可以。资源页路径向导选择 LoRA 文件夹类型，直接选择或输入实际目录，保存并读取。不要把只含权重的目录误当成完整引擎根目录。

### UI 格式工作流为什么仍要求导出 API？

普通 UI 图可以结合运行中的 ComfyUI 节点定义转换；旁路、Primitive、复杂插槽和未知前端语义不能可靠推断时，会明确要求 API 格式，避免看似载入成功却改变实际绘图含义。


### 进度显示的是整段工作流还是当前采样节点？

NeoForge 使用本次任务接口返回的进度。ComfyUI 的节点耗时各不相同，因此显示当前节点实际步数和百分比，不用节点数量拼成虚假的总进度。模型载入、解码和保存时可能没有逐步百分比；这些阶段显示等待，最终接收图片后自动收起。

### 旧图片多了以后，图库会一直在后台刷新吗？

不会。0.2.4 改为分页缩略图，折叠时停止读取。任务面板使用轻量摘要；历史记录和原图保留在本机，不靠删除旧数据来加速。
