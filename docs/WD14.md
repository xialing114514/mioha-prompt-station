# WD14 本地模型安装与排错

[手册目录](README.md) · [快速上手](QUICK_START.md)

> **只有模型本体不够。** 每个模型需要 **ONNX 权重 + 同一版本配套的 `selected_tags.csv`**。CSV 负责把输出序号对应到标签；缺少它，软件不会把该模型列为可用。

## 1. 准备正确的文件

从你有权使用的 WD14 模型项目下载实际 ONNX 文件与配套 CSV。例如 [SmilingWolf 的 wd-v1-4-convnextv2-tagger-v2 文件页](https://huggingface.co/SmilingWolf/wd-v1-4-convnextv2-tagger-v2/tree/main) 提供 `model.onnx` 和 `selected_tags.csv`。

两份文件应来自**同一个模型仓库、同一个版本**。不要把 A 模型与 B 模型的 CSV 混用。软件当前插件读取 ONNX；不能直接把 `.safetensors`、`.pth`、`.pt` 或 TensorFlow 的 `.pb` 当成这个 ONNX 文件使用。

下载时取得实际文件，不是保存网页。Git LFS 指针是几行文本，不是完整模型。也不要把 `.onnx` 和 `.csv` 只放在压缩包里。

## 2. 打开软件实际使用的模型目录

进入「图片反推」，点「打开模型文件夹」。**以软件打开的目录为准**，避免把文件放进其他软件的模型目录或旧安装目录。

推荐每个模型单独一个子文件夹：

```text
梧桐提示词站的安装目录/
├── 梧桐提示词站.exe
├── app-runtime/
├── runtime/
│   └── tagger/
│       └── mioha-tagger.exe
└── models/
    └── wd14/
        ├── wd-convnextv2/
        │   ├── model.onnx
        │   └── selected_tags.csv
        └── 另一个兼容模型/
            ├── model.onnx
            └── selected_tags.csv
```

关键是两份文件位于**同一层目录**。ONNX 文件可以保留上游文件名；`selected_tags.csv` 使用这个准确名称。Windows 隐藏扩展名时，留意不要变成 `selected_tags.csv.txt`。

## 3. 扫描并选择模型

放好文件后回到「图片反推」点「扫描模型」，在 WD14 模型下拉框中选择它。状态行会显示可用模型数量；缺少标签文件、CSV 表头不正确或下载到网页／LFS 指针时，会说明未启用原因。

反推方式选择「本地 WD14 插件（离线）」。不需要启动 NeoForge 或 ComfyUI，使用安装包附带的独立反推运行组件即可。不要移走 `runtime/tagger`。

## 4. 用一张没有生成元数据的图片测试

有元数据时，软件优先展示原始参数，**不会为了测试而重复调用 WD14**。没有元数据时才使用所选插件；有参数但需要重新读图，可移除图片后再按实际需求操作。

WD14 输出的是模型预测标签与置信度，不是原始提示词、真实底模或 LoRA 加载记录。降低阈值通常会增加标签，也可能增加误判。

## 常见放置错误

| 现象 | 原因与处理 |
| --- | --- |
| 扫描显示 0 个模型 | 先确认选的是本软件「打开模型文件夹」打开的目录，再检查 ONNX 与 CSV 是否同层 |
| 只放了 `model.onnx` | 补上同仓库同版本的 `selected_tags.csv` |
| CSV 放在父目录或其他子目录 | 移到对应 ONNX 的旁边，重新扫描 |
| CSV 叫 `selected_tags.csv.txt` | 显示文件扩展名后改为正确名称 |
| CSV 表头不正确 | 下载实际 CSV，应有 `name`、`category` 等模型标签列，不能是网页内容 |
| 模型文件只有很小的文本内容 | 可能是 Git LFS 指针或下载错误，重新下载实际权重 |
| 提示标签数量与模型输出不匹配 | 模型与 CSV 版本不一致，重新取得配套文件，不要自行拼接标签表 |
| 找到模型但运行组件缺失 | 还原安装包的 `runtime` 目录，必要时重新安装程序；保留自己的模型与数据备份 |
| 模型已列出，但 ONNX 加载失败 | 确认是兼容的 WD14 ONNX 模型、文件完整，并保留上游要求的其他配套文件 |
| 图片读出了参数但没有跑 WD14 | 这是元数据优先逻辑；原始参数比预测标签更直接 |

软件不附带、不自动下载模型。本页面的链接用于帮助定位文件；模型的使用权限和许可仍以原作者说明为准。
