# NAI 在线法典与本地风格库

[手册目录](README.md) · [模型、LoRA 与生图](MODELS_AND_GENERATION.md)

## 浏览原站资料

打开「绘图资料中心 → NAI 法典」，选择词典，再选择「单画师词典」「画风组词典」或素材。来源为 [NovelAI QuickTagCloud](https://novelai.quicktagcloud.com/)，接入实现参考 [NovelAI-Tag](https://github.com/AgIzT/NovelAI-Tag)。

程序按原站目录和条目顺序展示，支持搜索、多标签 AND 筛选、模型版本与分页。切换分类会取消旧查询，保存条目也不会改变原站次序。原站内容更新后可点击「刷新原站资料」。

词条按需读取，最近使用的词典保留在程序内存中；图片按需加载并使用有界缩略图缓存。整套词典不打包进安装器，也不会上传到本项目的服务器。首次读取大型词典的耗时取决于网络，网络请求使用软件设置的出口；指定代理失败时不会自动改为直连。

## 保存到本地

点击条目上的「保存到本地」，在「画师与风格」建立本地资源，保留原始画师串、权重、换行、介绍、负面提示词、标签、模型版本、来源链接、预览链接及来源快照。

保存成功后可「查看本地」。再次保存不会重复创建，也不会覆盖自己编辑过的名称、文本或封面。已保存文本离线可用；选择原站预览链接时，查看图片仍需要联网。要离线查看封面，可在本地编辑器上传 PNG、JPEG 或 WebP 图片。

## NAI 生图加载画师串

1. 在「连接生图」选择 NovelAI，并配置自己的 NovelAI Token。
2. 展开「NAI 画师串」，选择一个或多个本地 NAI 画师串，也可填写本次补充文本。
3. 检查正向、负面、模型及参数，然后点击生成。

画师串仅在提交请求时与正向提示词组合，不修改选词页或生图页的提示词框。记录保存当次使用的真实文本和资源快照；其他模型的画师串不会自动套用到 NAI。画师串选择与其他生图后端独立保存。
