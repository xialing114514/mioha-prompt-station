# 数据、隐私与备份

[手册目录](README.md)

## 本地目录

个人数据位于 `%USERPROFILE%/.mioha-prompt-forge`，包括本地数据库与个人配置。安装目录保存程序、运行组件、用户放入的 WD14 模型等。

更换安装目录与卸载程序不会主动清除用户数据目录。做大版本升级、迁移电脑或批量修改前，使用设置中的数据导出；模型／Skill 的配置导出与完整个人数据备份用途不同。

普通创作数据并非全部加密。凭据使用当前 Windows 用户的加密保护；不要把整个个人目录、数据库或凭据文件公开上传，也不要把复制受保护文件当成跨 Windows 账号迁移方案。

## 哪些操作会联网

| 操作 | 数据会送到哪里 |
| --- | --- |
| 免费 AI 通道 | 描述、对话及为任务提供的上下文发送到对应第三方服务 |
| 自定义 AI／视觉接口 | 发送到用户配置的接口；视觉任务可能包含图片 |
| 本地 WD14 | 在本机运行，不需要在线模型服务 |
| 模型信息与预览获取 | 访问相应来源、图片地址与用户配置的网络出口 |
| GitHub 更新检查 | 匿名读取公开版本信息，不发送创作数据库或发布凭据 |
| 自建云同步 | 在用户连接的服务器之间同步受支持的数据 |

免费服务的可用性、记录方式和限制以提供方条款为准。涉及敏感创作资料时，先确认所选模型与服务的数据处理方式。

## 云同步范围

本地可先保存，连接自己的云服务后再同步受支持的设置、角色／预设修改、存档与翻译记忆等。离线时继续使用已保存的本地资料。

云同步不是整台电脑的文件备份，也不代表所有模型权重、LoRA、Skill 目录或运行组件都会上传。来源资料索引、图片缓存与个人创作备份应分别管理。

## 内容模式

全局内容显示设置保存在本机，不通过普通云同步自动解锁另一台设备。安全模式隐藏标记或命中的 NSFW 标签／资料，对未知分级预览保守隐藏；已有资源和原始数据保留。

这是一项内容显示与请求偏好，不是通用图片鉴定服务，也不授予外部模型额外权限。

## 反馈时如何脱敏

保留软件版本、引擎、错误信息和必要步骤；遮盖 Key、Agent Token、含凭据的链接、私人对话、数据库内容及个人路径。不要直接公开完整个人目录或日志包。
