# 创作工作台

[项目主页](../README.md) · [使用手册](README.md)

## 从组合到批量实验

在「创作实验室 → 提示词组合」保存人物、服装、场景、风格或 LoRA 卡片。选择目标绘图模型后，把卡片放进组合并检查正负向输出。批量实验可以对服装、背景或其他变量枚举，也可以抽样或锁定部分变量。提交前先预览组合和任务数量。

完成后可在画风实验标记 Treasure、Special 或 Reject，再选父代做交叉或变异。用同一种子和基础组合更容易比较风格差异。结果同时保存在生成历史中。

## 分镜与酒馆

在「创作实验室 → 分镜项目」建立项目，填写全局角色外貌、服装、画风、光照和场景。每个画面可以覆盖这些设定，并添加镜头、构图和动作。点击「转换为模型提示词」，审阅结果后应用。生图配置从「连接生图」采用，生成多个候选后可以选主图，再按项目或场景导出 ZIP。

在「创作酒馆」导入或新建角色卡，绑定世界书并创建独立会话。对话中的方案建议可供审阅，确认后的版本可进入绘图流程。普通讨论与已确认方案分开保存。

## 工作流与蒙版编辑

在「连接生图 → 工作流管理」导入 ComfyUI API JSON，或放入工作流文件夹后刷新。普通界面 JSON 需要连接 ComfyUI 获取节点定义。检查依赖后可预览缺少的节点、权重与来源。确认后把可识别的项交给已运行的 ComfyUI-Manager 排队，完成时重新检查。

在「图像工作台」选择原图，展开「ComfyUI 图像工作流编辑」，检查一个有图片输入的工作流。选择原图节点与修改指令字段。工作流有蒙版输入时可在原图上画出修改区域。默认把指令追加到原字段，保留已有触发词。执行使用工作流中的模型、LoRA、采样和精度，结果可以保存为原图的关联副本。实际支持的局部重绘、去背景、超分或扩图由所选节点和模型决定。

## 图库与参考素材

生成历史支持按引擎、模型、LoRA、Seed、日期、来源和用户标注筛选。同一生成组共享收藏和评级。打开大图后可以滚轮缩放、拖动、复制图片、查看参数或发送到生图。也可独立浏览已选本地目录。

在「图像工作台」或「图库 → 参考素材」保存普通参考、Vibe 风格参考或精准参考。NovelAI 支持的模型和传输范围由界面检查，提交前需确认发送参考图片。当前精准参考适配 V4.5，Vibe 与精准参考分开使用。实际额度以账号和服务为准。[NovelAI 精准参考文档](https://docs.novelai.net/en/image/precisereference/)

已缓存的 Vibe 编码可以导出为 `.mioha-vibe.json`，在另一台设备用相同原图建立 Vibe 条目后导入。同一模型与提取信息量会复用该编码。此格式用于 Mioha 工作台之间备份，NovelAI 官方 Vibe 文件采用各自支持的格式。

## Agent 接入

Agent 使用自己的 Token 与会话，通过内置 AI 转换设计，再确认需要执行的生图与管理任务。可查询卡片和图库，管理本 Agent 的组合、实验、分镜和图像工作流。可用接口和工具从当前运行版本获取。[Agent 接入指南](AGENT.md)
