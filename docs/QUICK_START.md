# 快速上手

[手册目录](README.md) · [项目主页](../README.md)

当前版本为 **Windows 4.0.9 / Android 4.0.2 / Skill v24**。可以先在电脑上完成一次写词与生图，再配置手机连接。

## 1. 下载与安装

下载 `Mioha-Prompt-Station-4.0.9-Setup.exe` 并运行，选择安装目录与快捷方式。[4.0.9 发行页](https://github.com/xialing114514/mioha-prompt-station/releases/tag/v4.0.9)

- 需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。
- 安装包提供程序运行组件，普通使用无需安装 Python、Node.js 或打开命令行。
- `mioha-model-skills-v24.zip` 是可选的独立规则包；规则已包含在软件中。
- 软件不附带大语言模型、绘图权重或 WD14 权重，实际绘图引擎按需自行准备。

安装包未使用发布者数字签名。核对仓库地址和发行页 SHA256 后，再按系统提示安装。

### 已有版本怎么更新

先保存工作，并从托盘菜单「退出程序」，再覆盖安装到原目录。不要先清除个人数据。角色、配置与手机授权保留，升级前仍建议在设置中导出备份。

个人数据位于 `%USERPROFILE%/.mioha-prompt-forge`，安装目录与用户数据目录分开。4.0.0 的中文电脑名 DNSName / A-label 启动错误已修复，升级新版即可，无需改电脑名或删除证书。

## 2. 先写一条提示词

### 让 AI 整理

1. 打开「AI 选词」，选择实际要用的绘图模型规范，例如 Anima、MOSS、光辉或 NAI。
2. 免费模式选择清单中的可用模型；使用自己的服务时关闭免费模式，展开「自定义模型接入」填写接口、协议、模型 ID 和 Key。
3. 输入：“傍晚雨中的安静书店，暖灯、木地板、窗边绿植，没有人物，也不要画面文字。”
4. 左侧查看设计讲解，右侧检查提示词；可以继续补充，也可复制、追加／替换到选词页。
5. 使用自定义连接时，先点「测试连接」，成功后「保存」。测试使用当前模型、思考设置与生成通道，会发出短推理请求，服务商可能计费。

免费通道的默认模型为 NVIDIA: Nemotron 3 Ultra (free)，可用性与额度由提供方决定。程序保留已保存的选择，不会在免费服务失败时自动使用你的自定义 Key。

默认按 Enter 发送，Shift+Enter 换行；可在设置里切换为 Ctrl+Enter 发送。

### 自己选词和改权重

进入「提示词选词」，按中文或英文搜索，选择正向／负向后点击词条。展开「调整权重与顺序」，选中词条调整数值或拖动排序；中文释义就在对应词条下面。常用组合可存为预设／存档。

打开标签超市中的栏目后，搜索框只在所选栏目内找词。可以在「人物 → 五官与妆容 → 视线」找看向镜头的词，在「场景 → 家具 → 卫浴」找马桶和洗手池，或在「镜头 → 景深」找背景虚化。要跨栏查找时，切到顶栏的「全部」。

「AI 选词 → 绘图模型」决定提示词写法；实际加载哪份权重，在生图页单独选择。[详细 AI 配置与排错](BUILT_IN_AI.md)

## 3. 需要绘图时，连接自己的引擎

| 引擎 | 使用前准备 | 软件内操作 |
| --- | --- | --- |
| NeoForge / SD-WebUI | 启动对应 API 服务 | 「连接生图」选择引擎与实际 API 地址，读取模型、模块和 LoRA |
| ComfyUI | 启动 ComfyUI，准备权重与工作流 | 配置地址并选择工作流，检查参数映射与依赖 |
| NovelAI | 准备自己的 Token 和可用账户 | 选择 NovelAI，填写凭据与生图模型，按需加载本地画师串 |

常见本机地址为 `http://127.0.0.1:7860` 和 `http://127.0.0.1:8188`，以引擎实际启动地址为准。

点击「发送到生图」，核对提示词、模型、LoRA 和主要参数，然后生成。参数、LoRA、高清与增强插件按需展开，执行后查看进度和预览。[详细生图说明](MODELS_AND_GENERATION.md)

### 生图时替换 LoRA 或取消

展开「LoRA 与触发词」，选择已有项旁的「替换」即可试用新 LoRA；从空列表开始时用「添加 LoRA」。直接输入权重，停下后自动保存。已经提交的任务可以通过「取消生成」中止；[查看不同引擎的取消方式](MODELS_AND_GENERATION.md#取消生成)。

### 首次读取模型和 LoRA

在「模型中心」或「资源／LoRA」选择引擎，用路径向导选择自己的目录。LoRA 文件夹可独立读取；整个引擎目录选择对应类型。输入路径后按 Enter 或失焦会保存并读取，等待完成提示。

扫描目录用于显示资源，执行绘图需要运行中的引擎。搜索与绘图模型下拉框在列表上方；下载、批量工具和目录设置在「更多操作」中。

LoRA 文件夹显示“全部、根目录、用户文件夹”，点击文件夹浏览其内容。勾选资源后可「移动到文件夹」，权重和同名预览／元数据一起移动；管理菜单支持新建、改名和删除空文件夹。上下都有分页，翻页后自动回到顶部。[详细文件夹操作](MODELS_AND_GENERATION.md#lora-文件夹管理)

点击「详情／编辑」修改介绍与触发词，底部「确认保存并退出」提交，「取消」、Esc 或点空白退出未保存修改。填写并保存触发词后，再加载这个 LoRA 会自动带入。

## 角色配方保存与手动备份

在「绘图资料中心 → 角色配方」创建／编辑角色并保存。编辑区收起表示资料已提交到本机数据库，重启后可继续使用；大正文支持导入 UTF-8 TXT，本地容量受磁盘空间约束。

配方不自动上传。配置服务器连接后，点击「上传服务器」备份已保存内容；修改后需再次手动上传。工具栏的「从服务器下载」会校验备份后合并，同名或已有修改优先保留本地，下载不自动上传。

服务器所有用户共用 1 GB 总容量。空间不足、断网或上传失败不删除本地配方；完整上传并校验后才替换备份，重启不会自动重试。

## 图库与删除

进入「无边图像浏览」查看历史或选择本地目录。预览中的「发送到生图」会替换当前 LoRA，保留记录中的双权重；没有 LoRA 的图片会清空旧项。「来源与筛选」展开目录条件，「选择图片」进入多选。

**删除会移除图片文件，首次确认后记住选择，后续不再询问，也没有撤销。** 浏览指定目录时，会删除该目录里的原文件。升级不自动清理旧版删除区，需要时使用专门清理入口。[完整删除范围与操作](GALLERY.md)

## 手机与电脑连接

Android 下载同一发行页的 `Mioha-Android-4.0.2-arm64.apk`，可覆盖安装并保留资料。手机既可独立编辑，也可配对自己的电脑。

电脑在「连接与设置 → 远程连接」手动启用，手机扫描／粘贴连接码，电脑弹窗确认设备权限。每次启动远程仍默认关闭。[配对、回执、重连与 P2P 指南](MOBILE_REMOTE.md)
